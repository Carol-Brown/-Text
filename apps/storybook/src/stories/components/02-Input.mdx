## 选择控件决策

| 控件 | 使用条件 |
|---|---|
| 单选框 | 2–5 个互斥选项需要同时可见 |
| 下拉选择 | 选项较多、空间有限 |
| 复选框 | 独立多选或协议确认 |
| 开关 | 设置会立即生效的开/关 |

校验尽量在失焦或提交后发生。错误说明问题和修复方式；禁用控件仍要保持内容可读。
