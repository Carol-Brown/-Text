# 加载与骨架屏

<div className="xw-doc-demo xw-doc-demo--stack">

  <Skeleton lines={4} />
</div>

Spinner 用于控件或短暂、结构未知的等待；Skeleton 用于结构已知的首次内容加载。已有有价值内容时不要用骨架屏覆盖。长时间 AI 或系统任务必须升级为带阶段和控制的 Progress。

减少动态效果开启后降低动画频率；加载状态要通过辅助技术播报，但不要连续重复打扰。
