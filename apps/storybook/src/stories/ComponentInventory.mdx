# 小微组件总览

| 标记 | 含义 |
|---|---|
| 现有 | 6.0 页面中已有稳定实例 |
| 修正 | 已出现，但需要统一样式、状态或行为 |
| 新增 | 6.0 缺失，由本系统补齐 |
| 按需 | 已纳入目录，但只在出现真实业务场景时实现 |
