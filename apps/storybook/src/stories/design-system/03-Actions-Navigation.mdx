# 操作与导航

## Button（现有，修正）

| 变体 | 用途 | 限制 |
|---|---|---|
| Primary | 页面或弹窗的唯一首要行动 | 同一作用域最多一个 |
| Secondary | 次要但明确的行动 | 可与 Primary 并列 |
| Tertiary / Text | 低强调、工具栏操作 | 不用于高风险确认 |
| Danger | 删除、断开、覆盖等不可逆操作 | 文案写明对象和后果 |
| Icon | 高频、含义稳定的紧凑操作 | 必须有 tooltip 与可访问名称 |

尺寸沿用现有节奏：页面主按钮 180×48；large 高 36；medium/small 高 32。状态必须覆盖 default、hover、pressed、focus-visible、disabled、loading。Loading 保持原宽度且阻止重复提交。

按钮文案用“动词 + 对象”：`开始扫描`、`上传文件`、`删除知识库`；避免泛化的“确定”。取消始终是次要按钮，危险操作的默认焦点不得落在危险按钮上。

## Link（补充）

用于导航或打开资源，不模拟按钮。外部链接标注外跳；下载显示文件类型/大小；正文链接有下划线或其他非颜色线索。

## Navigation Rail（现有，修正）

固定承载一级模块：当前项清晰选中；图标与名称稳定；低频设置置底。折叠时提供 tooltip。徽标只显示需要处理的数量，不用作促销装饰。

## Tabs（现有，修正）

用于同一对象的平级视图，不用于顺序步骤。默认不超过 6 项；标签短而互斥；切换保留未提交内容时需提醒。内容加载可独立显示 skeleton。

## Menu / Dropdown（现有，修正）

菜单承载动作，Select 承载值。按使用频率排序，危险操作单独分组并靠后。支持方向键、Enter、Esc；打开后焦点进入首个可用项。

## Breadcrumb（补充，按需）

仅用于知识库、设备详情等三层以上层级。首页和模块入口无需面包屑。最后一级为当前页，不可点击。

## Steps（补充）

用于有明确顺序、可命名阶段的任务，例如导入知识库、设备修复、工作流创建。状态为 waiting / active / complete / error / disabled；步骤数推荐 3–5。步骤不是进度条，不能用不确定的技术子任务充数。

## Pagination（补充，按需）

仅用于无法连续加载且需要定位页码的长列表。一般桌面列表优先筛选 + 虚拟滚动或“加载更多”；分页时保留筛选和排序状态。
