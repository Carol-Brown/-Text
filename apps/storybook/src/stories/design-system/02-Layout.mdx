# 布局与界面层

## 应用壳层（现有，修正）

主窗口由窗口栏、72px 左侧导航、内容区和可选右侧面板组成。导航保持固定；内容独立滚动；右侧面板用于详情、证据或持续任务，不替代模态确认。

| 宽度 | 行为 |
|---|---|
| ≥ 1180 | 导航 + 主内容 + 可选 320–400px 辅助面板 |
| 900–1179 | 辅助面板覆盖或折叠，主内容保持最小可用宽度 |
| 720–899 | 导航仅保留图标，双栏改为单栏 |
| < 720 | 进入紧凑窗口；隐藏非关键工具，不缩小文字到不可读 |

## Grid / Stack / Space（补充）

- 页面横向留白 24；卡片网格间距 16；密集列表 8–12。
- 内容最大宽度：阅读型 760，表单型 640，仪表盘随窗口扩展。
- `Stack` 管理单方向间距，`Grid` 管理重复卡片；禁止靠空白字符或空 div 调距。

## Card（现有，修正）

用途：聚合一个对象、一组指标或一个可执行任务。结构为 header / body / footer，可选媒体区和状态区。

- 变体：standard、interactive、selected、status、flat。
- 状态：default、hover、focus、selected、disabled、loading、error。
- 整张卡可点击时，内部不要再放多个相互冲突的主操作；复杂卡片只让明确按钮可点击。
- 标题不超过两行；描述不超过三行；完整内容进入详情页或展开区。

## Divider / Section（补充）

优先用间距和标题分组；只有边界不清晰时使用 1px 分隔线。不要用阴影、背景和分割线同时分层。

## Split View（现有，修正）

适用于文字提取、知识库、会议笔记等“来源 + 结果”任务。默认 40/60，可拖拽至 30/70–70/30；任一侧不得小于 320px；记住本地用户比例。窄窗口切换为标签页，不并排挤压。

## Floating Surface（现有，修正）

桌面悬浮球、展开胶囊和持久任务卡属于独立层：不遮挡系统关键区域；可拖动；靠边吸附；打开主面板后减少重复内容。悬浮球只承载入口和一项即时状态，不承载复杂确认。

## Drawer / Side Panel（补充）

用于查看详情、筛选或非阻断编辑。推荐宽度 360 / 480，最大 640；从右侧进入；保留原页面上下文。涉及不可逆提交时，仍使用对话框确认。
