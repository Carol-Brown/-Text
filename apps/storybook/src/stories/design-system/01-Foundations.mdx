# 基础规范

## Color tokens

禁止在组件规范里使用 `purple-500` 一类与用途无关的名称；组件只消费语义 token。

| 角色 | Light | Dark | 说明 |
|---|---:|---:|---|
| `color.brand.primary` | `#6663FF` | `#7465F5` | 主要行动、选中和焦点 |
| `color.brand.hover` | `#5652F5` | `#8477F7` | 悬停 |
| `color.brand.pressed` | `#4642F0` | `#6553F0` | 按下 |
| `color.text.primary` | `#16152A` | `#F5F6FA` | 标题、正文重点 |
| `color.text.secondary` | `#66707E` | `#C9CDD7` | 正文、说明 |
| `color.text.tertiary` | `#8F95A0` | `#9DA4B3` | 辅助信息 |
| `color.text.disabled` | `#B7BDC6` | `#666C79` | 禁用，不用于低对比正文 |
| `color.surface.page` | `rgba(248,249,255,.88)` | `rgba(13,13,13,.88)` | 页面/大面板 |
| `color.surface.card` | `#FCFCFE` | `#1B1D24` | 卡片、弹窗 |
| `color.surface.subtle` | `#F6F5FF` | `#110F25` | 选中、分组背景 |
| `color.border.default` | `#E5E7EB` | `#2A2D36` | 普通边界 |
| `color.border.strong` | `#D1D5DB` | `#383B46` | 输入/分隔强化 |
| `color.status.success` | `#22C55E` | `#37D67A` | 成功 |
| `color.status.warning` | `#F59E0B` | `#FFB020` | 风险/需注意 |
| `color.status.danger` | `#F26063` | `#FF6B73` | 失败/破坏性操作 |

品牌渐变只用于品牌强调或 AI 主行动：`#4642F0 → #A38CFF`。不得用于长段文字、状态色或大面积正文背景。旧稿中的不同蓝紫渐变归并到这一 token，产品皮肤差异另建主题，不继续新增硬编码。

## Typography

默认字体栈：`Microsoft YaHei UI, Microsoft YaHei, PingFang SC, system-ui, sans-serif`。数字密集区域可使用系统等宽数字特性。

| Token | 字号/行高 | 字重 | 用途 |
|---|---:|---:|---|
| `display` | 36/60 | 700 | 欢迎页主标题，慎用 |
| `heading-lg` | 24/32 | 700 | 页面标题 |
| `heading-md` | 20/28 | 700 | 区块标题 |
| `heading-sm` | 16/24 | 600 | 卡片、弹窗标题 |
| `body` | 14/22 | 400 | 默认正文 |
| `body-strong` | 14/22 | 600 | 正文强调 |
| `label` | 13/20 | 600 | 控件标签 |
| `caption` | 12/18 | 400 | 辅助信息 |
| `micro` | 11/16 | 400 | 仅用于非关键元信息 |

## Spacing, radius, elevation

- 间距基数为 4：`4, 8, 12, 16, 20, 24, 36`；`10` 仅保留给已有紧凑控件。
- 圆角：小控件 `4`，输入/小卡片 `8–12`，主卡片与弹窗 `16`，胶囊 `999`。
- 阴影：卡片 `0 2px 8px rgba(0,0,0,.06)`；悬浮层 `0 8px 24px rgba(0,0,0,.10)`；焦点不得只依赖阴影。
- 层级：基础内容 0；吸顶/侧栏 100；下拉与浮层 200；抽屉 300；模态 400；全局通知 500。

## Icons

使用单一线性图标语言。默认 24，状态/选择 20，行内 16，强调 32。图标按钮必须有文本名称；纯装饰图标从辅助技术隐藏。状态不能只靠颜色区分。

## Motion

微交互 120–180ms，面板 180–240ms；强调移动不超过 320ms。使用 `ease-out` 进入、`ease-in` 离开。进度动画只表达真实活动，支持系统“减少动态效果”。

## Density and theme

默认密度用于 1200×800 主面板；紧凑密度仅用于表格、文件列表、设备列表。主题切换必须保持语义角色，不允许用“反色”临时替代深色设计。
