# 组件文档模板

### Behavior

说明打开、关闭、提交、取消、溢出、异步、失败、恢复和窗口缩放。

### Content

给出推荐和不推荐的中文实例；规定标题、说明和按钮的长度或句式。

### Accessibility

键盘操作、焦点、角色/名称/状态、动态播报、对比度、缩放和减少动画。

### Tokens

只列语义 token；如必须新增 token，说明它无法复用现有角色的原因。
