# 无障碍与文案

## Keyboard and focus

- 所有功能可仅用键盘完成；Tab 顺序与视觉顺序一致。
- `focus-visible` 使用 2px 品牌色外环并与背景保持对比；不要移除系统焦点而无替代。
- Esc 关闭非破坏性浮层；方向键操作菜单、Radio、Tabs；Enter/Space 激活控件。
- 模态关闭后焦点返回触发它的控件；动态结果用礼貌级 live region 宣布，不抢焦点。

## Target and scaling

紧凑桌面控件可视高度最低 32px，主要操作推荐 40–48px；纯图标按钮也要有足够点击区域。必须在 Windows 100%、125%、150%、200% 缩放和高对比度模式下检查，不以固定像素裁掉内容。

## Color and media

正文、控件边界和状态满足 WCAG 2.2 AA 对比度；颜色不是唯一线索。图片有替代文本；装饰图片隐藏；音频/会议能力提供实时文字或转写后的等价内容。

## Language

- 用用户语言描述任务：`正在检查启动项`，不写模糊的 `处理中…`。
- 标题说结论，正文给原因，按钮说行动。
- 不用“失败了”“未知异常”结束对话；至少给一个可执行的恢复路径。
- 危险提示包含对象、影响、是否可恢复。
- 预计时长不可靠时写阶段，不编造倒计时。

## AI trust

AI 生成内容标注来源和生成状态；事实、建议和系统执行结果要可区分。执行前确认高风险边界，执行后给变更记录。不要展示拟人化“思考过程”来替代真实进度或证据。

## Accessibility acceptance checklist

- [ ] 键盘能到达并触发全部行动。
- [ ] 焦点可见，弹窗焦点管理正确。
- [ ] 200% 缩放下无裁切或关键操作丢失。
- [ ] 错误、进度和结果有文字表达。
- [ ] 图标按钮有可访问名称和 tooltip。
- [ ] 动效遵循减少动态效果偏好。
- [ ] 屏幕阅读器能感知控件名称、状态和动态更新。
