# 数据展示

## List（现有，修正）

用于同构对象。行结构为 leading / title+description / metadata / status / actions。默认只显示一个主行操作，其余进入菜单。行选择与行打开必须可区分，批量模式出现后提供已选数量和清除选择。

## Table（现有，修正）

用于需要跨列比较的数据：文件、设备、扫描项和知识条目。表头明确单位；首要列左对齐，数字右对齐；操作列固定。支持排序、筛选、空状态、加载、行错误和批量操作。小窗口隐藏低优先级列或转为详情抽屉，不做横向无限挤压。

## Tag / Badge / Status（现有，修正）

- Tag：分类或可移除筛选，文本短，避免整句。
- Badge：数量或新事件，不能替代状态文字。
- Status：success / warning / danger / info / neutral，必须有图标或文字，不只用颜色。
- 同一含义全产品只用一种色彩，例如“处理中”统一为 info，而不是随模块变色。

## File Item（现有，修正）

统一展示文件名、类型图标、大小、来源、处理阶段和操作。超长文件名保留扩展名并可悬停查看完整名称。删除本地记录和删除源文件必须明确区分。

## Empty（现有，修正）

空状态包含：发生了什么、为什么、下一步。区分首次空、筛选无结果、权限导致不可见和加载失败。主操作最多一个，例如“上传第一份资料”；不要用庆祝插画掩盖错误。

## Skeleton / Placeholder（补充）

用于结构已知、预计超过 300ms 的初次加载。形状接近最终内容，避免整页闪动；不用于按钮提交或不可预测的 AI 生成，后者使用任务进度。

## Collapse / Description / Statistic（补充）

- Collapse：技术细节、证据、日志；关键结论不可折叠隐藏。
- Description：设备属性、保修信息等键值对。
- Statistic：健康度、数量、时长；必须给单位、时间范围和解释。

## Content Preview（现有，修正）

文档、识别文本、会议笔记采用可缩放预览 + 结果编辑。预览和编辑区明确同步状态；自动保存显示“已保存/保存失败”；复制、导出、定位原文是结果型内容的标准操作。
