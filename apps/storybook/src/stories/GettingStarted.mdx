# 小微设计系统

这是独立于研发 Repo 的设计验证与交付工作台。组件、设计规则、交互状态和后续 Prototype 都在同一套 Storybook 中演进。

当前版本按照“通用、布局、导航、数据录入、数据展示、反馈、业务组合”七类组织，共 90 个可独立浏览条目。每个条目包含视觉示例、使用说明和状态验收。

## 本地启动

```bash
pnpm install
pnpm storybook
```

## 推荐工作方式

1. 先在 `@xiaowei/tokens` 中建立语义变量，再实现组件。
2. 每个组件同时维护 API、视觉状态、交互状态和无障碍行为。
3. 新业务界面先在“业务模式”中组合验证，稳定后再进入原型。
4. 只把已通过评审的公共模式沉淀回“组件”。
